Запуск из копии актуального репозитория на машине с входными данными:

```bash
# Сначала активируйте установленный ROOT (source .../bin/thisroot.sh).
bash proof/run_statistics_diff.sh
```

По умолчанию используются `config/kt.json` и `config/y.json`. Можно задать
новую папку результатов и выбранный конфиг:

```bash
bash proof/run_statistics_diff.sh statistics_diff_real config/kt.json
```

Требуются ROOT, CMake >= 3.20, компилятор C++17 и зависимости проекта.
Скрипт собирает отдельную цель `statistics_diff`. Входные файлы открываются
только для чтения; обычные результаты анализа не перезаписываются.
Указанная папка результатов должна отсутствовать.

В каждой папке конфига сохраняются:

- `fits.csv`: повторные фиты с программной ошибкой, ROOT `B` и ошибкой
  независимых гистограмм; параметры, ошибки и статусы фита.
- `cells.csv`: исходные моменты N, S, Q и сравнение ошибок по ячейкам.
- `fit_over_cf.csv`: ошибки диагностического отношения до исправления и
  по формуле `abs(fit)*sigma_CF/CF²`, при одной и той же кривой.
- `chi2_cells.csv`: отдельные слагаемые ручной суммы χ².
- `chi2_check.csv`: сравнение ручной суммы и ndf с программой.
- `rounding.csv`: влияние округления S до 2, 4, 6 и 8 знаков при неизменных
  N и Q. Это эксперимент над сохранёнными моментами; потерянную точность
  накопления TH3F он не восстанавливает.
- `errors.csv`, `README.txt`, `config.json`: ошибки проверки моментов,
  условия расчёта, путь входа, версия ROOT и использованный конфиг.

Нулевой дифф ошибки fit/CF допустим: если старая гистограмма кривой уже
имела нулевые ошибки, исправление только явно закрепляет это поведение.
Фиты с `B` и независимыми ошибками — сравнение чувствительности, а не
подтверждение применимости этих моделей. Для событийных корреляций нужны
событийные данные. Сырые ошибки в таблицах не включают программную проверку
разрешимости дисперсии относительно округления; отрицательная дисперсия
обозначена `nan`, без взятия модуля.

Ручная сумма поддерживает используемые в обоих конфигах фиты по центрам
ячеек с опцией R и диагональными ошибками. Интегральные, likelihood,
Pearson и фиты с единичными ошибками явно отклоняются.

После выполнения можно упаковать результаты:

```bash
tar -czf statistics_diff_real.tar.gz statistics_diff_real
```

CSV по всем ячейкам могут быть большими. Не интерпретируйте параметры
провалившихся фитов или фитов на границах как физический результат.
