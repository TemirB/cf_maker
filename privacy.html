CFMakerLabReports — личный инструмент автоматизации научных расчётов из проекта TemirB/cf_maker. Его работу настраивает и контролирует владелец проекта.

Какие данные обрабатываются

  • PDF-отчёты с графиками и результатами научного анализа.
  • Метаданные расчёта: commit SHA, идентификатор запуска, время выполнения, коды завершения и контрольные суммы.
  • Метаданные файлов Google Drive: имена, идентификаторы, папки, размеры и контрольные суммы, необходимые для проверки загрузки и обновления отчётов.
  • OAuth-учётные данные и токены, необходимые для разрешённого пользователем доступа к Google Drive.

Логи расчётов могут содержать имена файлов и локальные пути. Исходные файлы научных данных остаются на лабораторном ПК; при публикации передаются PDF, метаданные запуска и диагностические логи.

Для чего нужен доступ к Google Drive

Используется разрешение https://www.googleapis.com/auth/drive.file. Оно даёт доступ к файлам, созданным приложением, и к отдельным файлам, доступ к которым пользователь явно предоставил приложению.

Публикатор создаёт папки отчётов и PDF-файлы, читает их метаданные для проверки загрузки, сохраняет историю версий и обновляет latest.pdf. Данные Google Drive используются для этих действий. Полный доступ ко всем файлам Диска не запрашивается.

Где находятся данные и кто их обрабатывает

Расчёты выполняются на лабораторном ПК. Перед публикацией PDF, манифесты и хвосты логов передаются через GitHub Actions Artifacts. PDF и их файловые метаданные сохраняются в Google Drive.

Доступ к артефактам и журналам GitHub Actions определяется настройками и видимостью репозитория. В публичном репозитории они не являются закрытым каналом передачи отчётов.

По инструкции проекта рабочие OAuth-учётные данные хранятся в GitHub Environment secrets и передаются облачному заданию публикации. Лабораторному runner эти секреты не передаются. Публикатор не меняет настройки общего доступа к файлам в Google Drive.

Для работы используются сервисы Google и GitHub. На них также распространяются политика конфиденциальности Google и политика конфиденциальности GitHub. Эти информационные страницы размещаются на GitHub Pages и не подключают собственные аналитические скрипты.

Сроки хранения

Исторические отчёты в Google Drive и локальные результаты хранятся до удаления владельцем. В подготовленном workflow срок хранения GitHub Artifacts составляет 30 дней. Срок хранения журналов GitHub Actions определяется настройками репозитория.

Отзыв доступа и удаление

Отозвать доступ приложения можно в настройках подключений Google-аккаунта. Это прекращает дальнейший доступ по отозванному разрешению, но не удаляет уже сохранённые отчёты.

Для удаления копий данных владелец может удалить файлы из Google Drive, артефакты и журналы из GitHub Actions, а также локальные результаты и логи. Неиспользуемые OAuth-секреты следует удалить из GitHub Environment.

Связь с владельцем

По вопросам работы приложения и обработки данных можно обратиться к владельцу через Issues репозитория cf_maker.
