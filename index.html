CFMakerLabReports

Личный инструмент для запуска научного анализа и сохранения PDF-отчётов в Google Drive.

Приложение предназначено для владельца проекта и его лабораторной работы. Оно использует проект cf_maker для анализа корреляционных функций и проверки результатов фитов.

Как работает приложение

  1. Изменения кода в GitHub запускают сборку и расчёты на настроенном лабораторном ПК.
  2. После успешного расчёта формируется PDF с графиками и диагностикой.
  3. Облачное задание GitHub Actions загружает отдельную версию отчёта в Google Drive и обновляет latest.pdf.

Доступ к Google Drive

Приложение запрашивает разрешение drive.file. Оно используется для работы с файлами приложения: папкой отчётов, историей версий и последним успешным отчётом.

Порядок обработки данных, их хранения и отзыва доступа описан в политике конфиденциальности.
