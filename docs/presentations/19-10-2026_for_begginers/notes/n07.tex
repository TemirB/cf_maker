\textbf{Тезис:} корреляционная функция сравнивает совместное распределение пары с независимым ожиданием.

\textbf{На экране:} учебный спектр слева и два импульса на нём → \(f\) и \(f_2\) справа → отношение C → независимый уровень C = 1.

\textbf{Текст:} Чтобы говорить о такой связи количественно, начнём с графика слева. Он показывает, какие значения одной компоненты импульса встречаются чаще. Пунктир отмечает два выбранных импульса; расстояние между ними — разность этих значений.

Справа сверху этому соответствует одночастичное распределение f. Ниже введено f-два: оно отвечает на другой вопрос — какие два импульса встречаются вместе.

В формуле C совместное распределение делится на произведение двух одночастичных. Общая нормировка N задаёт единичный уровень независимого фона. Поэтому C = 1 означает независимое ожидание; C выше единицы — пары встречаются чаще этого ожидания, ниже — реже. C является отношением, а не ещё одной плотностью.

\textbf{Переход:} Для описания пары удобно явно выделить разность импульсов и их среднее.

\textbf{Справка:} В определении C используются плотности выходов частиц и пар с согласованной общей нормировкой. Гауссов график слева — учебный нормированный спектр p-x, не эксперимент и не SMASH. Нельзя отождествлять его с двухчастичной плотностью. Корреляции создаются не только обменной интерференцией, но и распадами, законами сохранения и регистрацией.
